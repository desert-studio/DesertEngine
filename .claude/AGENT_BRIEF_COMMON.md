- Тестовые `.make` есть только после `CI=true premake5 gmake`. Никогда не убивай чужие процессы `make`.
- Любое другое ожидание > 4 мин (тесты, мигратор) — тоже кусками ≤ 4 мин блокирующими вызовами, не простоем.

## Engine vs scripts (owner 2026-09-27)
The engine owns MECHANISMS and data formats; game RULES live in scripts. The engine never names game concepts: no slots,
items, "equip", and no bone/socket/body-part names (`"head"`, `"hand_r"`, `"Spine"`) in engine code — a turtle's helmet
goes on `"shell"`. Names come from assets (skeleton sockets, data assets) and are passed in by scripts or content.
Examples and tests may use concrete names; engine headers/sources may not hard-code them.
