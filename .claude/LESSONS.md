## Сборка и машина
- Сборка, оборвавшаяся на имени файла в логе, — убита; перезапустить. Убивать процесс по имени образа нельзя:
  `taskkill /IM MSBuild` снимает все параллельные сборки.
- LNK1168 без своего процесса — exe держит игра владельца (античит): перелинковать под другим именем, не убивать.
- `cl` на 0 % CPU с одним файлом — зависание компилятора (тернарный аргумент по значению): бисекция копий с таймаутом.
- Лог замер, `cl` в ожидании PageIn — pch вытеснен с HDD: один раз прочитать .pch, не убивать.
- Компиляция за 2 с после правки заголовка — протухшее попадание ccache: удалить obj, `CCACHE_RECACHE=1`.
- `lib.exe` виснет на 4 ГБ (/GL + /Z7 в Release): LTCG только в Shipping.
- Link редактора в Release замирает после pdb при 0 CPU/0 IO: проверить дважды, снять по PID, перезапустить.
- Старые obj ThirdParty новее исходников по mtime дают ложный assert (meshopt): удалить Intermediates.
- Тяжёлая сборка на нормальном приоритете душит прокси и память: приоритет и число потоков задаёт скрипт сборки.
- Пользовательская VULKAN_SDK перекрывает установленный SDK: экспортировать явно.
- Символ `\b`, сохранённый как 0x08 в регулярном выражении, делает перепись молча мёртвой: проверять `git grep -P`.
- `\n` в python-heredoc из Git Bash становится настоящим переводом строки: скрипт — файлом, не heredoc-ом.

## Замеры и кадры
- ПК заблокирован — GPU в P8, все проходы в 1,5–7 раз медленнее: замеры недействительны, гонять только визуальное.
- Монитор выключен — 4 FPS и ~200 мс «Unaccounted»: не регрессия.
- Много проходов в 10–100 раз медленнее — VRAM выше бюджета (подкачка WDDM): смотреть `VRAM budget` в логе.
- 0 VUID и чёрный кадр: ничего не нарисовано. Сначала среднее кадра и `did not execute`.
- «Размытая тень» на миниатюре оказалась 0,013/255: разница — числом.
- Машинные настройки владельца подделали регрессию в 3458 пикселей: побайтовое сравнение — при настройках по умолчанию.
- Потолок метода GI в машинных настройках только ограничивает; запрашивает сцена: проверять, каким методом снят кадр.
- `--camera` без `--shot` игнорируется; режим вида переживает перезапуск редактора.
- Свёрнутое окно редактора останавливает съёмку («no drawable area»): развернуть, не убивать.
- `play_scenario` при одной Release-сборке находит старый Debug-редактор: проверять, какой бинарник запущен.
- Bistro снимается из репозитория проекта, не из старой локальной копии (пустая сцена с rc=0).
- NVIDIA на Windows не проверяет включение BC-сжатия: отсутствие ловит только перепись исходников.
