# THE FILES THAT HAVE PAID FOR THESE DEFECTS, AND THE CHECKS THEY MAY NEVER SHOW AGAIN.
#
# WHY A REGISTER AND NOT "THE WHOLE TREE". The check set in .clang-tidy reports 67 406 distinct source
# locations over this workspace, so a tree-wide gate would be red on day one and would be switched off
# within a week — which is the exact state this repository's .clang-tidy was found in. The changed-lines
# gate covers code as it is written. This register covers the other direction: a file that was cleaned
# of a defect CLASS stays clean for that class forever, including in the lines nobody is touching.
#
# WHY IT IS A LIST OF ROWS AND NOT A COUNT. A gate that pins a NUMBER can be satisfied by editing the
# number. Each row below is a file, verified clean for every check in CHECKS at the commit that added it.
# Adding a row is free; removing one is a decision that has to be argued in a commit message.
#
# HOW IT RUNS:  scripts/CI/CheckTidy.sh --register      (or as the second half of the default gate)
# Exit codes are the script's: 0 clean, 1 a finding, 2 the gate could not run.
#
# ------------------------------------------------------------------------------------------------------
# The seven classes Д36 closed. Each is a defect with a mechanism, not a style preference:
#
#   unchecked-optional-access ....... dereferencing an empty optional is undefined behaviour, and
#                                     `.value()` inside a constructor is std::terminate with no handler.
#   suspicious-memory-comparison .... memcmp over a type with no unique object representation: -0.0f and
#                                     0.0f are one value and two bit patterns, padding is uninitialised.
#   exception-escape ................ an exception leaving a destructor or a main is std::terminate.
#   implicit-widening-of-multiplication-result ... a 32-bit product used as a 64-bit offset has already
#                                     overflowed by the time the wider type sees it.
#   incorrect-roundings ............. `(int)( x + 0.5 )` truncates toward zero, so it rounds negatives
#                                     the wrong way.
#   assignment-in-if-condition ...... an `=` that reads as an `==` at a glance.
#   empty-catch ..................... a handler indistinguishable from a forgotten one.
#
# NOT in this list, and each absence is deliberate:
#   bugprone-branch-clone ........... 14 live findings, all switch arms that legitimately share a body.
#                                     Not looked at by Д36; a row would be a claim nobody has checked.
#   concurrency-mt-unsafe ........... 23 live findings after Д36, all getenv/system/exit in
#                                     single-threaded startup and editor paths. See the task report.
