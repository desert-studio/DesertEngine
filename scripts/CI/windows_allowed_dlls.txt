# DLLs the packaged Windows game (Runtime.exe, and every DLL shipped beside it) may import — read by
# scripts/CI/CheckWindowsDlls.sh.
#
# Two kinds of entry:
#   * SYSTEM: present on every supported Windows (10+) install, or installed by the GPU driver the game
#     needs anyway. Nothing ships it.
#   * `app-local`: NOT on a clean Windows install, so the package must carry it next to Runtime.exe.
#     The check refuses a package where an imported app-local DLL is missing — an allowed name is not
#     proof the player has the file. Today these are the Visual C++ runtime DLLs: the workspace builds
#     with the DLL CRT (/MD) because the Vulkan SDK's shaderc and spirv-cross libraries are stamped
#     RuntimeLibrary=MD_DynamicRelease, and Editor/Source/Editor/Packaging/GamePackager.cpp copies the
#     ones the binary imports from the redist of the Visual Studio that built it.
#   The DEBUG CRT (VCRUNTIME140D, MSVCP140D, ucrtbased) is never allowed: Microsoft does not license it
#   for redistribution, and GamePackager refuses a Debug Runtime by name.
#
# Format: NAME [app-local]  # reason. NAME is case-insensitive and may be a glob (`*`). A new entry names
# the code that imports it; "the check went red" is not a reason.

KERNEL32.dll   # the Win32 base; every executable imports it (and the CRT sits on it)
USER32.dll     # GLFW's win32 backend: windows, messages, input (ThirdParty/GLFW/src/win32_*.c)
GDI32.dll      # GLFW's win32 backend: pixel formats, device contexts
SHELL32.dll    # GLFW's win32 backend: DragAcceptFiles / DragQueryFileW for file drops
dwmapi.dll     # GLFW links Dwmapi.lib (BuildScripts/ThirdParty/GLFW.lua): composition / transparency
WS2_32.dll     # Optick's capture server socket (#pragma comment(lib, "ws2_32.lib") in optick_server.cpp)
DbgHelp.dll    # Optick's symbol resolver (#pragma comment(lib, "DbgHelp.Lib") in optick_core.win.h)
PSAPI.DLL      # process memory readout (#pragma comment(lib, "psapi.lib") in Common/Utilities/ProcessMemory.cpp)
vulkan-1.dll   # the Vulkan loader: installed by every Vulkan-capable GPU driver, never shipped by a game

# The Universal CRT: an OS component since Windows 10 (System32); /MD code imports it through these apisets.
api-ms-win-crt-*.dll   # UCRT apisets, part of Windows 10+ (the /MD CRT's C half)

# The Visual C++ runtime (/MD's C++ half) — shipped app-local by GamePackager (PK-W1).
VCRUNTIME140.dll            app-local  # shipped app-local by GamePackager (PK-W1): every /MD image
VCRUNTIME140_1.dll          app-local  # shipped app-local by GamePackager (PK-W1): x64 C++ exception handling (__CxxFrameHandler4)
MSVCP140.dll                app-local  # shipped app-local by GamePackager (PK-W1): the C++ standard library
MSVCP140_1.dll              app-local  # shipped app-local by GamePackager (PK-W1): <memory_resource>
MSVCP140_2.dll              app-local  # shipped app-local by GamePackager (PK-W1): C++17 special maths
MSVCP140_ATOMIC_WAIT.dll    app-local  # shipped app-local by GamePackager (PK-W1): C++20 atomic wait / <stop_token> / <semaphore>
MSVCP140_CODECVT_IDS.dll    app-local  # shipped app-local by GamePackager (PK-W1): <codecvt> facet ids
CONCRT140.dll               app-local  # shipped app-local by GamePackager (PK-W1): Concurrency Runtime (only if <ppl.h>/<concrt.h> is reached)
